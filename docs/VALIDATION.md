# Validation — initial prototype

Performed on 2026-10-03, Linux x86_64 / KDE, system Qt 6.11.2 and Python 3.14.7.

- Pinned Kotonoha native bridge built successfully against system Qt / LayerShellQt.
- 14 SingLayer tests passed: revision-3 parsing, sparse metadata, pause/seek,
  two browser connections, removal/disconnect, invalid data, stale clock bounds,
  WebSocket handshake, webpage origin rejection, confirmed/rejected commands,
  real D-Bus properties, and the actual Kotonoha MPRIS consumer.
- 85 selected upstream tests passed: `test_overlay.py`, `test_overlay_platform.py`,
  `test_mpris.py`, using Qt offscreen rendering.
- Actual X11 renderer smoke: `platform=xcb`, native layer-shell correctly disabled.
- Actual isolated KWin Wayland renderer smoke: `platform=wayland`, `layer_shell=True`.
- Upstream live native blur lifecycle test: 1 passed, 17 deselected. It recreated
  real Wayland surfaces and checked cleanup of native blur objects.
- Preview PNG generated by Kotonoha's actual widget using original demo text.

The virtual Wayland test ran inside its own D-Bus and runtime directory. It did not
replace the desktop session. It proves native library loading and rendering in
KWin, not click-through/fullscreen stacking on every desktop or monitor layout.

Not yet verified: extension setup in Brave/Vivaldi; live SoundCloud/Spotify/YouTube
timing and provider matches; audio recognition; queues; altered playback speed.
Do not describe the prototype as end-to-end verified for those services yet.
